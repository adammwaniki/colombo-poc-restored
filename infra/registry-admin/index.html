What you can do here. Look up a citizen, then issue them any credential the register supports — a Grama Niladhari address certificate, a cultivator credential or fertilizer voucher (fertilizer-subsidy use case), or a business permit — each signed by its issuing authority. Hand it to the citizen with Download (for their wallet); any other office confirms it by an API call — the citizen never has to present it. Edits write straight to the registry (Postgres + Elasticsearch).
